# Adaptive AI Mock Interview System - Backend API

FastAPI backend service powering the Adaptive AI Mock Interview platform.
Connects to Supabase PostgreSQL for persistent data storage.

## Features
- AI Mock Interview planning, dynamic real-time questioning, and turn actions
- STT transcript processing & custom NLP intent classification
- Multi-dimensional answer evaluation & scoring rubric
- Dynamic styled PDF report generation matching design specifications
- ATS resume analysis and job matching
- Supabase PostgreSQL persistence
